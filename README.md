# Flavora 2026 - Food Festival

Flavora 2026 is a responsive food festival event microsite created as a web development milestone project.

## Pages

- Home
- Schedule
- Highlights
- Register

## Technologies Used

- HTML5
- Tailwind CSS
- Git
- GitHub

## Features

- Responsive festival website
- Event schedule
- Food highlights
- Ticket information
- Registration form
- Venue map
- Sponsor/partner section
- Responsive navigation
